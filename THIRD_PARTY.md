# Components and attribution

Original coursework authorship, notes, Git history and existing licenses remain. No new blanket license is applied to historical code. The original README credits are retained verbatim.

- Spring Boot 2.4.5, Thymeleaf, Hibernate, H2, Lombok and test dependencies keep their existing declarations/notices. No dependency upgrade or new runtime library is introduced.
- The original Takari Maven Wrapper 0.5.6 JAR was compared with its official Maven Central artifact before execution. Its old scripts do not enforce modern checksum properties; this is an audit-time comparison, not a claimed runtime SHA gate. [Official wrapper documentation](https://maven.apache.org/wrapper/).
- Outfit is a locally served Google Fonts distribution under SIL OFL 1.1. The complete [license and copyright notice](DojoNavalManuel/src/main/resources/static/fonts/OFL.txt) accompanies the font. No font provider is called at runtime.
- The new small SVG favicon is original code-native artwork. Historical media files remain attributed to their existing context and are not loaded by the new interface; no unverified image license is invented.
- New fictional fixtures and real application screenshots contain no employer/client materials. Generated visual references remain internal and are not runtime/public screenshot assets.

Formatting tools were kept outside source exports; their binaries are not application dependencies. Public code, resources and evidence are exported only from explicit reviewed paths.
